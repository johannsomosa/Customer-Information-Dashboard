# Customer-Information-Dashboard for KTM Motorcycle company
An informational dashboard on Excel, utilizing Pivot Tables, charts, and other key excel functions to identify and visualize sales demographics for the Austrian motorcycle company KTM.


# Problem Statement
Extracting actionable insights from raw sales data can be challenging without a streamlined, visual approach. Understanding sales demographics is critical for optimizing marketing strategies, improving customer targeting, and driving revenue growth.

This project addresses the need for a comprehensive informational dashboard in Excel to analyze and visualize KTM's sales demographics effectively. Key goals include:

1. Data Organization: Structuring raw sales data into a format suitable for analysis using Pivot Tables.
2. Demographic Insights: Identifying key sales demographics, such as customer age, location, income levels, and product preferences.
3. Visual Representation: Utilizing Excel charts (e.g., bar graphs, pie charts, heat maps) to create an intuitive, interactive dashboard.
4. Trend Analysis: Highlighting seasonal sales trends, regional performance variations, and customer buying behavior.

## Included Concepts:
- Charts
- Data Visualization tools
- Vlookups
- Pivot Tables
